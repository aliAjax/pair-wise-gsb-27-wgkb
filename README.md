# 物流分批发货 · 阶梯结算台账

- 行业：物流
- 技术栈：Vue3、Vite、TypeScript、Pinia、Element Plus
- 启动：`npm install && npm run dev`
- 构建：`npm run build`

## 业务规则

客服按客户 + 线路分批发货，系统按「客户 + 线路 + 月份」累计计费重量并分档计价：

- **阶梯折扣**：本月累计前 50 吨原价，50–100 吨降 3%，超过 100 吨降 6%。
- **计费重量**：`max(实重, 体积 m³ × 200kg)`，即每立方米折 200 公斤。
- **冷链加价**：冷链服务在折后运费上加 15%。
- **跨档拆段**：一批货若让累计吨数跨过档界，自动按档界拆成多段分别计价（如批前 40 吨再发 20 吨：10 吨原价 + 10 吨 97 折）。
- **已结算不改价**：批次一旦结算即锁定试算价；若实际结算价与阶梯试算价不一致，差额登记到「待确认差额」，区分应退/应补收并单独核销，不回改历史批次。
- **重开可核对**：数据保存在浏览器 localStorage，重开页面可继续核对累计吨位、各批拆段金额与待确认差额。

## 目录分层

| 层 | 目录 | 职责 |
| --- | --- | --- |
| 资料 | `src/data/` | 类型定义、阶梯档位/换算常量、初始演示数据 |
| 阶梯计价 | `src/pricing/tiered.ts` | 纯函数：计费重量、跨档拆段、批金额、差额，不依赖存储和页面 |
| 保存 | `src/storage/local.ts` | localStorage 读写、种子初始化、恢复出厂 |
| 业务状态 | `src/store/settlement.ts` | Pinia store：批次/差额的增删、结算、核销、按组汇总 |
| 页面 | `src/components/`、`src/App.vue` | 录入试算表单、累计核对表格、待确认差额列表 |

- `components/BatchForm.vue`：新增批次，实时预览体积折算、累计档位、跨档拆段金额。
- `components/GroupList.vue`：按客户/线路/月份展示累计吨位、档位进度条、每批拆段金额与结算入口。
- `components/PendingDiffs.vue`：待确认 / 已确认差额，支持核销。

这是一个功能最小闭环前端项目，数据保存在浏览器 localStorage 中，方便后续扩展接口、权限、图表或地图能力。
